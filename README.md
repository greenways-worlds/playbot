# Playbot

A Greenways world demonstrating PlayCanvas streamed SOG loading through
`lod-meta.json` and its repository-relative resources.

Open it in Greenways OS with:

```text
https://github.com/greenways-worlds/playbot
```

## Studio touchpoint

The world declares an `Open Studio` touchpoint near Playbot. In a Greenways OS
viewer with world-surface support, activating the touchpoint opens the installed
browser-native music Studio. Audio files dropped into that interface remain
local browser objects while Hara carries the logical track list and active
surface state.

The touchpoint is ignored safely by older viewers that only understand the SOG
layer.
